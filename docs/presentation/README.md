# Presentation

`ResolvIQ-deck.html` — a self-contained 12-slide deck (no dependencies, no build).

## Present
Open `ResolvIQ-deck.html` in any browser.
- **Navigate:** ↓/→/Space forward, ↑/← back, `Home`/`End` to jump. Or use the ↑/↓ buttons (bottom-right).
- Full-screen the browser (F11 / ⌃⌘F) for presenting.

## Export to PDF
Browser **Print** (⌘P / Ctrl+P) → **Save as PDF**. Each slide is a page; set margins to *None* and enable *Background graphics*.
